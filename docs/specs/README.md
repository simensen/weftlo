# Specifications

This directory contains feature specifications for Weftlo.

## Documents

| Document | Description |
|----------|-------------|
| [profiles.md](./profiles.md) | Profile system specification (creation, inheritance, merging) |

## Purpose

Specifications detail:
- **How** specific features work
- State machines and lifecycles
- Data schemas and validation rules
- Edge cases and error handling
- Integration points between components

## Guidelines

- These are living documents that evolve with implementation
- Reference ADRs for "why" decisions were made
- Link to reference docs for command syntax
- Keep lookup tables in `reference/`

See [DOCUMENTATION-GUIDE.md](../DOCUMENTATION-GUIDE.md) for complete guidelines.
