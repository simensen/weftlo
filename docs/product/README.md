# Product Documentation

This directory contains product-level documentation for Weftlo.

## Documents

| Document | Description |
|----------|-------------|
| [vision.md](./vision.md) | Product vision, problem statement, and key concepts |
| [roadmap.md](./roadmap.md) | Future considerations and planned enhancements |

## Purpose

Product documentation defines:
- **What** we're building and **why**
- Problem statements and success criteria
- Core concepts and glossary
- Non-goals and explicit boundaries
- Future direction and planned features

## Guidelines

- Content here should be stable and rarely change
- Focus on strategy, not implementation details
- Reference ADRs for major decisions
- Keep technical specifications in `specs/`

See [DOCUMENTATION-GUIDE.md](../DOCUMENTATION-GUIDE.md) for complete guidelines.
