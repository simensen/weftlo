# Reference Documentation

This directory contains reference documentation for Weftlo.

## Documents

| Document | Description |
|----------|-------------|
| [cli.md](./cli.md) | CLI command reference with all options and flags |
| [configuration.md](./configuration.md) | Configuration file formats and options |
| [templates.md](./templates.md) | Template syntax, functions, and variables |

## Purpose

Reference documentation provides:
- Lookup information for commands and options
- Configuration schemas and defaults
- Error codes and their meanings
- Quick answers to "what are the options?" questions

## Guidelines

- Be exhaustive — cover all options
- Use tables and lists for scannability
- Keep examples brief; detailed examples go to appendices
- Reference specifications for conceptual context

See [DOCUMENTATION-GUIDE.md](../DOCUMENTATION-GUIDE.md) for complete guidelines.
