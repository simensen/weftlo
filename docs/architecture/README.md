# Architecture Documentation

This directory contains architecture documentation for Weftlo.

## Documents

| Document | Description |
|----------|-------------|
| [overview.md](./overview.md) | System architecture, layers, and component relationships |

## Purpose

Architecture documentation shows:
- How the system's components relate to each other
- System context and container diagrams
- Network topology and communication patterns
- Cross-cutting concerns (error handling, logging patterns)

## Guidelines

- Diagrams are primary, text supports them
- Reference ADRs for architectural rationale
- Link to specifications for detailed component behavior
- Keep implementation details in `implementation/`

See [DOCUMENTATION-GUIDE.md](../DOCUMENTATION-GUIDE.md) for complete guidelines.
